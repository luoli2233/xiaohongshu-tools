# 试玩与交接手册

适用：客户端0.1.0 H5首次开发版。面向演示者、策划、后续接手开发者。

## 1. 开场准备

在game目录运行`npm start`，打开普通地址进行正式试玩，或加`?debug=1`打开开发演示台。建议手机竖屏或390px左右浏览器窗口。保持一个正式游戏标签页，避免本地存档同时写入。

首次正式局会展示教学。已有存档时先用“继续”，需要新局则确认覆盖。称号保留。暂停页可导出JSON快照和日志，存储失败时不要刷新，先导出数据。

## 2. 约5分钟演示脚本

| 时间段 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:45 | 打开正式局或完整练习局，选择日常工作 | 每天先选重点；技能成长、老板好感、快乐是不同目标 |
| 0:45–1:30 | 跟随教学工作5秒、发呆3秒 | 点选持续执行；工作耗精力，摸鱼恢复且快乐增长 |
| 1:30–2:15 | 开发台安全巡视/手机被抓快照 | 预警不处罚；观察开始即检查；手机收手1.2秒仍危险 |
| 2:15–3:00 | 暂停，显示目标与一次事件 | 看规则时暂停；选项明确成本；追加任务奖励等到日末 |
| 3:00–3:45 | 第3天晋升快照→查看评估 | 技能与好感两个门槛同时满足；新职级次日生效 |
| 3:45–4:30 | 晋升路线与幸福路线快照 | 职场成绩与幸福感可分别追求；多称号可选择 |
| 4:30–5:00 | 展示暂停保存、返回继续、导出日志 | 可以中断；快照是演示数据，不进入正式最佳 |

演示台快照跳过了此前过程，不能将它们当作真实玩家成绩。演示台“模拟日末”用于核验当前状态的结算，不是标准玩法中的加速按钮。

## 3. 独立试玩安排

计划邀请5–8名喜欢轻量职场题材的体验者。每人先完成一局，再自由选择第二种路线。此安排尚未执行，不存在真实用户满意度或完成率数据。

首局除卡住外尽量不指导，避免把演示者知道规则误当成用户理解规则。只记录具体观察：在哪天、几秒、什么动作、界面提示是什么、玩家以为会发生什么。

## 4. 调参方法

先核对理解与反馈，再讨论数值。多人看不懂收手，先改反馈；不要立即降低巡视难度。多人只选一种重点，比较各重点的完成率、成长和精力压力，再修改一组相关参数。

使用同一固定种子复测改变前后版本，同时保留自由随机试玩。配置变动升级版本；旧存档按现有策略明确拒绝，不静默替换参数。不要用演示快照推导真实晋升率。

可采集指标：完整局完成率、首局中断天数、被抓与识破次数、成功摸鱼时长、各日重点与目标达成率、3/6/9天职级、最终职场成绩/幸福感、第二局选择变化。当前无自动上传，本机JSON按需人工汇总。

## 5. 日志说明

导出文件包含`exportVersion`、完整`run`与日志数组。单条日志有唯一id、工作日、游戏毫秒、类型、文字原因，并在属性变更事件中附before/after/key；巡视、事件、结算带关联ID。

快速排查被抓：按day查找PATROL_WARNED、PATROL_STARTED、ACTION_CHANGED、PATROL_CAUGHT；再查看对应patrol的start/end、caught、exposed和penaltyApplied。正常情况下同一巡视只罚一次，但识破后再摸鱼仍计caught。

排查任务失败：检查当日focus、dayRank、modifiers和最终progress；以settlement的target为准。任务中途达标不提前发好感，后续加量或错误会改变最终结果。

排查恢复：检查schema、configVersion、phase/resumePhase、elapsedMs、pendingAction、wrapMs/restMs、随机状态和已结算标记。原始坏存档可以从首页导出，不手动补字段后声称恢复成功。

## 6. 交付与接手步骤

1. 阅读README并启动，实际完成第一天。
2. 阅读开发说明的模块边界、时钟、巡视和存档章节。
3. 跑33项规则测试和构建，核对当前版本。
4. 阅读需求差异表；先处理工程看板P1项，不自动打开扩展功能。
5. 根据下一阶段目标决定正式美术制作或平台技术验证。

工程提供源码、文档、测试和本机构建，没有远程仓库、部署凭证、平台账号、外部API密钥或线上工单。Git仓库已初始化在game目录，未创建远程、未推送、未打发布标签。

## 7. 常见问题

**打不开游戏**：确认Node版本和终端的Game ready提示；4173端口已被占用时可设置PORT后启动。不要从文件协议直接打开HTML。

**手机打不开电脑地址**：确保同一局域网并使用电脑局域网IP，不使用手机自身localhost。检查防火墙；本工程没有改动网络策略。

**计时突然停了**：检查是否切后台、窗口失焦、打开教学/事件/目标，点击继续。暂停期间不会补算收益。

**提示存档版本不匹配**：导出原始存档后开始新局。此版本不静默迁移旧参数。

**刚刚完成目标，日末却没达标**：检查追加事件或低精力错误，日末使用最终目标和最终进度。

**分享没弹出**：浏览器和协议不一定支持原生分享；系统会尝试剪贴板或文本导出。真实平台分享尚未接入，取消不影响成绩。

**如何停止**：在本地服务终端按Ctrl+C或关闭启动窗口。下次运行同一地址和浏览器即可继续本机存档。
