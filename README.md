## 当前版本重点

- 10 个工作日，每天 60 秒有效游戏时间；周一至周六推进，跳过周日。
- 工作提升技能和交付，摸鱼恢复精力与快乐；装忙也有被识破风险。
- 六类事件配套插画，第 3 / 6 / 9 天职级评估，最终解锁称号并按快乐评价。
- 未完成任务逐日结转：今天差 4 点，明天选择基础目标 14 点的学习任务，总目标为 18 点。
- 合成循环音乐默认开启，首次点击启动，切后台停止；不打包音频文件。
- 全页面横屏，竖屏容器中旋转游戏与弹窗。

**数据边界：**存档和留言仅保存在当前浏览器，尚不支持其他玩家看到留言、账号、云同步或联网排行榜。公开仓库不代表游戏已上线，也不会自动提供公网试玩地址。

**验证范围：**39 项规则测试、语法检查和构建通过；做过本地 Chromium 界面与音乐启动检查。Chrome 61、Android / iOS 真机、小红书容器音频与性能仍需实测。

**使用权：**当前未授予开放源代码许可证；公开可见不等于允许任意转载、商用或重新分发素材。

## 立即运行

安装 Node.js 20 或以上。在本目录运行：

```sh
npm start
```

打开 <http://localhost:4173>。Windows 也可以双击本目录的 `启动游戏.cmd`。
不需要 `npm install`：游戏、测试和本地服务器没有第三方运行依赖。

同一局域网手机可打开 `http://电脑局域网IP:4173`；电脑防火墙须允许该端口。本项目没有自动修改防火墙。服务器绑定 `0.0.0.0`，用于局域网试玩，不是互联网生产服务器。

开发源码使用 ES Module，应通过本地 HTTP 服务加载。`npm run build` 会输出可离线加载的经典脚本交付目录。

## 当前可玩内容

- 10 天 × 每天 60 秒有效时间，首局暂停式教学。
- 工作、假装很忙、发呆、刷手机；收手和获准休息为独立状态。
- 精力效率、技能成长、低精力错误、三种工作重点。
- 老板预警、观察、识破、被抓、工作认可、假脚步和概率折返。
- E01–E06 六个事件，并按事件类型切换独立事件画面；第 3/6/9 天评估、晋升、降职和失败。
- 日末流水、双成绩结局、平均快乐评价、六种可同时解锁的称号。
- 本机自动存档、暂停与中断恢复、个人最佳和最近 100 局记录。
- 演示快照、固定随机种子、属性调试和日志导出。
- 十五张原创横屏状态与事件美术随动作、巡视和突发事件切换；按钮音效可统一开关。上传包不包含音频文件。

美术为原创程序像素场景，遵循上级目录 `ART_DIRECTION.md` 的配色和办公室层次。参考图未被直接用作带有假按钮的背景；角色动作、老板进出、真实数值由游戏驱动。当前像素细节和动画帧数属于原型级。

## 操作

| 操作 | 方法 |
| --- | --- |
| 工作 / 摸鱼 / 装忙 | 点击底部三个按钮，或按 1 / 2 / 3 |
| 发呆 / 手机 | 选择摸鱼方式后点“摸一会儿”；已在摸鱼时切换方式会触发原动作收手。键盘 4 / 5 可直接请求对应动作 |
| 暂停 | 右上角暂停；键盘 P 或 Esc |
| 评估目标 | 点击任务面板“评估目标”，查看时暂停 |
| 保存退出 | 暂停后“保存并回到首页” |
| 导出日志 | 暂停页“导出快照和日志” |

手机收手 1.2 秒，发呆收手 0.2 秒。收手期间没有收益且仍可能被抓，不显示“正在收好”。假装很忙耗精力较少，但老板观察中 2 秒后开始有概率被看穿，累计 4 秒仍会被稳定识破。

手机竖屏预览时，页面会自动旋转为横屏显示，并禁止手动缩放。平台若支持工具级横屏配置，仍建议在平台后台同步选择横屏方向。

## 演示入口

打开 <http://localhost:4173/?debug=1>，首页显示“开发演示台”。支持安全巡视、手机被抓、第 3 天晋升、晋升路线结局、幸福路线结局、完整练习局、指定天数和属性。

所有快照和练习局强制 `demo=true`，不会覆盖正式存档，也不会更新称号与最佳记录。正常地址没有开发面板。前端不是防作弊边界，不用于联网排行榜。

## 检查与构建

首次克隆仓库后，先运行 `npm ci` 安装构建依赖，再执行以下检查。运行和测试不需要第三方运行依赖。

```sh
npm test
npm run check
npm run build
```

可选：美术原件保存在 `design-source/02_art/`；安装 Python Pillow 后执行 `python scripts/prepare-assets.py` 可重新生成压缩图片。背景音乐由 `src/music.js` 实时合成。宣发图片保存在 `promo-v0.2.6/`。

`dist/` 是小红书小游戏可接收的离线 H5 构建目录：入口位于根目录 `index.html`，资源均使用相对路径，无网络依赖，JavaScript 构建目标为 Chrome 61 / Android 8.1。

可选浏览器冒烟验证见 `scripts/browser-smoke.mjs`，需要外置 Playwright 与 Edge/Chromium。它不影响正常运行。

## 文件结构

```text
game/
├─ index.html                 # 横屏双栏工位和可访问 HTML 控件
├─ src/
│  ├─ config.js               # 稳定 ID、工作重点、事件、称号
│  ├─ engine.js               # 无 DOM 的确定性规则引擎
│  ├─ storage.js              # 快照校验、原子存储、个人记录
│  ├─ scene.js                # Canvas 像素办公室和动作表现
│  ├─ app.js                  # UI 流程、输入、生命周期、存档编排
│  └─ style.css               # 配色、横屏布局与响应式
├─ scripts/                   # 本地服务、构建、可选浏览器验证
├─ tests/engine.test.mjs       # 35 项规则回归
├─ docs/                      # 开发、管理、验收和交接
├─ artifacts/                 # 浏览器验收截图与机器报告
└─ dist/                      # npm run build 生成
```

项目使用本机存档，无账号和后台。清理浏览器站点数据会丢失进度；浏览器隐私模式/存储配额不足时显示存档错误，可导出排查。
